⇌ fileSend beta
🚩 mclohrk · mclohrk.xyz

Durante um pentest, precisamos constantemente transferir arquivos para a máquina alvo (binários, scripts, exploits) e também exfiltrar dados de interesse. Montar esses comandos repetidamente consome tempo. O fileSend automatiza essa montagem: preencha os dados uma vez e os comandos prontos aparecem para colar direto na shell do alvo. Suporte a envio e exfiltração para alvos Linux e Windows, com múltiplos métodos de transferência.

⚠️ Versão beta — pode conter erros ou comandos incompletos. Teste antes de usar em campo. · 🤝 Contribua no GitHub
Como usar
1
Preencha os campos abaixo com seu IP, a porta que vai usar e o caminho do arquivo que quer enviar.
2
Escolha a aba do sistema alvo (Linux ou Windows) e selecione o método de envio.
3
Bloco 🖥 ATACANTE rode na sua máquina. Bloco 🎯 ALVO cole na shell do servidor que está atacando.
4
Clique em copy em qualquer bloco para copiar o comando pronto para o clipboard. Use ⬇ Exportar PDF para baixar todos os comandos gerados em PDF.
